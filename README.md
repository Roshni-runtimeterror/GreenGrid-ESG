🌿 GreenGrid AI

Smart ESG Monitoring Dashboard

GreenGrid AI is a simple and responsive ESG (Environmental, Social and Governance) monitoring dashboard designed to help organizations understand and track their sustainability performance.

The dashboard provides a quick overview of ESG performance through metrics, goals, carbon-emission visualization, and AI-style sustainability insights.

---

🚀 Features

- 📊 ESG Score — Overall sustainability score
- ⚡ Energy Monitoring — Track energy performance
- 🌍 Carbon Tracking — Monitor carbon emissions
- 💧 Water Usage — View water consumption
- ♻️ Waste Management — Track recycling performance
- 🤖 AI Insights — Simple sustainability recommendations
- 🎯 ESG Goals — Monitor sustainability targets
- 📱 Responsive Design — Works on desktop and mobile

⚙️ Installation

1. Clone the repository

git clone roshni-runtimeterror/greengrid

2. Open the project

cd greengrid-ai

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL provided by Vite in your browser.
